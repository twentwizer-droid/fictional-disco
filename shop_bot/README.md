# Telegram-бот-витрина магазина

Бот показывает ассортимент, цены и наличие в ваших магазинах, отвечает на вопросы
покупателей и полностью управляется из Telegram. **Продажа происходит только в магазине**:
в боте нет оплаты, бронирования и доставки (дистанционная продажа никотиносодержащей
продукции запрещена).

## Что умеет

**Для покупателя**
- проверка возраста 18+ при первом входе: без неё бот ничего не показывает;
- 🛍 Каталог: город → магазин → категория → товар → варианты (объём, крепость) с ценами
  и наличием именно в выбранном магазине;
- 🏬 Магазины: адрес, часы работы, телефон, точка на карте;
- 🔥 Акции, ℹ️ О нас;
- 💬 вопрос продавцу (общий или по конкретному товару); ответ приходит прямо в бота.

**Для админа** (`/admin`)
- ✏️ **Тексты и кнопки**: переименование *любой* кнопки и *любого* сообщения бота
  в два нажатия. Можно вернуть значение по умолчанию. В сообщениях сохраняется
  форматирование (жирный, курсив, ссылки). Старые подписи кнопок меню продолжают
  работать, а клавиатура у пользователя обновляется сама;
- 🏙 города и магазины: добавить, переименовать, удалить; адрес, часы, телефон, точка
  на карте (просто отправьте геолокацию);
- 📂 категории и товары: название, описание, фото, варианты с ценами;
- наличие: для каждого варианта переключатели ✅/❌ по магазинам, кнопки «есть везде» и «нет нигде»;
- 💬 вопросы: новый вопрос сразу приходит всем админам с кнопками «Ответить / Закрыть /
  Блок». Ответить можно кнопкой или просто **реплаем** на сообщение с вопросом.
  **Если на вопрос не ответили за 15 минут, бот напоминает админам** и повторяет
  напоминание каждые 15 минут, пока вопрос не будет отвечен или закрыт;
- 📢 рассылка (текст, фото, видео) всем, кто подтвердил 18+;
- 📊 статистика; блокировка пользователей.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой Telegram ID, например у @userinfobot.
3. Настройте и запустите:

```bash
cd shop_bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # впишите BOT_TOKEN и ADMIN_IDS
python bot.py
```

4. Напишите боту `/start`, затем `/admin` и заполните города, магазины, категории и товары.

### Docker

```bash
cd shop_bot
docker build -t shop-bot .
docker run -d --restart=always --env-file .env -v shop_data:/data --name shop-bot shop-bot
```

### Проверка

```bash
python test_e2e.py   # сквозной сценарий без подключения к Telegram
```

## Структура

| Файл | Что внутри |
|---|---|
| `bot.py` | запуск |
| `config.py` | настройки из `.env` |
| `db.py` | база SQLite и схема |
| `texts.py` | все тексты и кнопки со значениями по умолчанию |
| `user.py` | 18+, каталог, магазины, меню |
| `support.py` | вопросы, ответы, напоминания через 15 минут |
| `admin.py` | админ-панель |
| `middlewares.py` | проверка 18+ и блокировка |
| `ui.py` | клавиатуры и фильтры |

## Важно

Бот — информационная витрина. Перед запуском уточните требования вашего региона к
рекламе и информированию о никотиносодержащей продукции: в части регионов действуют
дополнительные ограничения.
